# AI Voice Automation Platform

## Vision

Build a SaaS platform where businesses can automate customer phone calls using AI.

The platform should allow companies to create multiple AI agents for different business workflows without writing code.

---

## MVP Goal

Build an AI Order Confirmation Agent.

Workflow:

CSV Upload
↓
AI Calls Customer
↓
Customer Confirms / Cancels
↓
Save Response
↓
Download Report
